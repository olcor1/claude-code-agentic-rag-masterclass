# External Integrations

**Analysis Date:** 2026-03-28

## APIs & External Services

**LLM Providers:**
- OpenAI-compatible chat endpoint - Main generation backend for chat, metadata extraction, workspace SQL, explorer-agent loops, and document sub-agents
  - SDK/Client: `openai` Python SDK in `backend/app/services/chat.py`, `metadata.py`, `workspace_sql.py`, `sub_agents.py`, and `explorer_agent.py`
  - Auth: `LLM_API_KEY` and `LLM_BASE_URL` in `.env`
  - Endpoints used: chat completions, embeddings, and JSON-formatted completions
- Optional local metadata model - Metadata extraction can switch to a locally configured model through `backend/app/services/local_llm.py`
  - Auth: `LOCAL_LLM_API_KEY`, `LOCAL_LLM_BASE_URL`, `LOCAL_LLM_MODEL`
  - Scope: metadata extraction path only

**External Search Providers:**
- DuckDuckGo HTML - Default web fallback provider in `backend/app/services/web_search.py`
  - Integration method: raw HTTP requests + HTML parsing with `urllib`
  - Auth: no API key required
  - Rate limits: not encoded in the repo; parser fragility is the main operational risk
- Tavily - Optional structured web-search provider
  - Integration method: REST API via `urllib`
  - Auth: `WEB_SEARCH_API_KEY`
  - Endpoints used: `https://api.tavily.com/search`

**Observability:**
- LangSmith - Optional tracing for chat, retrieval, metadata extraction, and other chains
  - Integration method: `langsmith.traceable` wrapper in `backend/app/services/tracing.py`
  - Auth: `LANGSMITH_API_KEY`, `LANGSMITH_PROJECT`, `LANGSMITH_ENDPOINT`

## Data Storage

**Databases:**
- PostgreSQL on local Docker - Primary datastore for users, conversations, folders, documents, ingestion jobs, and chunks
  - Connection: `DATABASE_URL` in `.env`, consumed by `backend/app/db/session.py`
  - Client: SQLAlchemy + psycopg
  - Migrations: ordered SQL files in `backend/migrations/`
- In-memory SQLite snapshot - Per-request analytical workspace mirror in `backend/app/services/workspace_sql.py`
  - Purpose: safe LLM-generated `SELECT` queries against a constrained schema
  - Lifetime: request-scoped only

**File Storage:**
- Local filesystem uploads - Source documents are stored under `backend/uploads/`
  - Client: direct file I/O in `backend/app/services/documents.py`
  - Auth: none beyond application auth and local filesystem permissions
  - Lifecycle: uploads are created on ingest and removed on deletion or cleanup paths

**Caching:**
- None currently
  - Retrieval, workspace SQL snapshots, and web search all execute live per request

## Authentication & Identity

**Auth Provider:**
- Custom JWT auth - The running code does not use Supabase Auth
  - Implementation: password hashing and JWT creation in `backend/app/core/security.py`; user resolution in `backend/app/services/auth.py`
  - Token storage: browser `localStorage` through `frontend/src/hooks/use-auth.tsx`
  - Session management: bearer token on API requests from `frontend/src/api/client.ts`

**OAuth Integrations:**
- None currently
  - No Google/GitHub/Auth0/OIDC configuration is present in the codebase

## Monitoring & Observability

**Error Tracking:**

**Analytics:**
