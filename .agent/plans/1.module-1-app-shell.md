# 🔴 Complex - Module 1 App Shell + Local RAG

## Summary
- Scaffold a full-stack app with React, FastAPI, local PostgreSQL + pgvector, custom JWT auth, local document ingestion, retrieval, streaming chat, and optional LangSmith tracing.
- Module 1 includes the first retrieval workflow rather than deferring RAG until Module 2.

## Key Changes
- Add a FastAPI backend with authentication, conversation APIs, document ingestion, pgvector-backed retrieval, and SSE streaming.
- Add a Vite React frontend with auth flows, document upload UI, conversation list, and a streaming chat surface.
- Add local infrastructure with Docker Compose for PostgreSQL + pgvector and a shared environment example.

## Validation
- Start PostgreSQL, run `python backend/scripts/init_db.py`, and verify schema creation.
- Run backend and frontend dev servers and confirm auth, upload, ingestion status polling, and streamed chat work.
- Configure LangSmith env vars and confirm traces are emitted; otherwise verify the backend logs tracing as disabled.

## Assumptions
- A local OpenAI-compatible endpoint is available for both chat completions and embeddings.
- Initial document support is limited to `.txt` and `.md`.
- Local uploads are stored in `backend/uploads/`.
